# Telegram Metadata Extractor Bot by Vlanter

Этот Telegram-бот создан для извлечения метаданных (EXIF) из фотографий. Он позволяет узнать дату съемки, модель устройства, GPS-координаты и другие скрытые данные.

## 🚀 Возможности
- Прием фотографий и файлов-изображений.
- Извлечение EXIF-тегов с помощью библиотеки `Pillow`.
- Расшифровка технических названий тегов в понятный текст.

## 🛠️ Установка и запуск
1. Установите зависимости:
   ```bash
   pip install pyTelegramBotAPI Pillow
2. Создайте файл config.py и поместите в него ваш токен:
    ```bash
   token = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
3. Запустите бота через терминал:
   ```bash
   python bot.py
